Conceptos principales de HTML

HTML

HTML es un lenguaje de marcado de hipertexto es un lenguaje de marcas que se utiliza para crear páginas web.

Elementos HTML

un elemento Html es la unidad basica de estrutura y contenido

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. contenido
  4. Etiqueta de cierre

Etiqueta <head>

Es una etiqueta que se utiliza para comunicarse con el navegador atraves de los metadatos, permite mejorar el SEO, ademas se enlaza archivos externos de estilos o scripts

Etiqueta <body>

dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semanticos

<Header> es una etiqueta para el contenido introductorio de una pagina web puede contener el logo, el menu de navegacion principal, el nombre de la empresa, etc.
<Nav> Etiqueta utilizada para el menu de navegacion principal suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal, no debe haber mas de uno en la pagina
<Main> Etiqueta unica de una pagina web cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra pagina
<Section> Es una etiqueta que poco a poco se intenta que sustituya a <Div>, su uso es para dividir una pagina web en secciones y agrupar contenido relacionado
<Article> Es una etiqueta que se utiliza para ocupar contenido autonomo, que si separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<Footer> es una etiqueta que normalmente se encuentra hasta el final de una pagina y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra informacion complementaria
<Aside> esta etiqueta representa una seccion de la pagina web cuyo contenido no esta directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados, etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras paginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/5061481615"
Este valor envia un whatsapp a un numero especificado
href="mailto:ejemplo@gmail.com"
enviaba un correo a un correo especificado

Elemento <Form>

es la manera en que los usuarios se pueden comunicar con una pagina web, gracias a este elemento se pueden procesar datos de los usuarios segun el objetivo de nustra pagina web
